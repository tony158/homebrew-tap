# Homebrew tap for ViralMint

[ViralMint](https://viralmint.net/) is an open-source video pipeline (clipper, AI video & more): trend scouting, AI clip extraction from long videos, script-to-video with captions and voiceover, AI video and image generation, and 40+ single-purpose video tools in one desktop app.

## Install

```sh
brew install --cask tony158/tap/viralmint
```

Apple Silicon Macs. The app is signed and notarized by Apple, so it opens without Gatekeeper warnings.

## Update / uninstall

```sh
brew upgrade --cask viralmint
brew uninstall --cask viralmint
```

Your projects and videos live in `~/ViralMint/` and are never removed by Homebrew.
